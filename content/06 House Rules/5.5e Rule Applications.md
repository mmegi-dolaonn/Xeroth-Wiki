For those unfamiliar in the party, WoTC released what was effectively dnd5.5e in 2024, offering a large number of additions, balancing adjustments and ability changes. While I know the original 5e (2014) much better and so we'll be using that, there are a number of good changes that I like from the updated edition that will be put into play for this campaign. 

A (non-exhaustive) list of these such changes can be found below, and more detailed explanations of the changes can be found from the original sources. 


## General Changes

- Exhaustion changes will be applied, now inflicting increasingly negative modifiers to checks and other rolls.
##  Class Changes

- All monk changes are applied. If making a monk, refer entirely to the 5.5e sources.
- The Path of the Berserker (Barbarian) subclass is using the 5.5e addition.
- The Rogue class is also using the 5.5e changes.

## Spell Changes

- (Mass) Healing Word and (Mass) Cure Wounds both gain their extra healing dice.
- 2024 True Strike in use.
- Ending Spell Early and Moving Spell rules are in play.
- 2024 Shillelagh in use.

## Weapon Changes

- Weapon Masteries have been applied to the campaign for use by martial subclasses.

## Combat Changes

- We will be using the 2024 rules for free object interactions, meaning swapping between 2 weapons in your turn is possible without sacrificing your action.
- We will be using the 2024 rules for Surprise, replacing the free surprise round with an advantage/disadvantage to initiative roles for the surprising/surprised parties.
